# Vision

Agent Companion becomes the most flexible AI platform for streamers and
content creators — an "Agent OS" where cooperating agents handle everything
from pre-stream planning, to live co-hosting, to post-production, while the
human stays in control.

## Three horizons

| Horizon | Phase | Shape |
|---|---|---|
| H1 — Personal tool | Sprint 1–2 | A live co-host that sees chat, speaks with the creator's voice, controls OBS, remembers the session |
| H2 — The crew | Sprint 3–4 | Multi-agent coordination: Director, Producer, Moderator, Researcher, Translator, Analyst on a shared workflow engine with session memory |
| H3 — Open platform | Sprint 4+ | Plugin SDK, marketplace, community agents, provider-agnostic, contributor-friendly |

## What Agent Companion is not

- Not a single chatbot.
- Not a replacement for the creator — the creator decides, agents suggest.
- Not a vendor lock-in tool — providers and models are swappable.
- Not a cloud service — local-first; the cloud is optional, never required.

## North star

A creator opens Agent Companion, goes live, and a small crew of invisible
agents runs beside them: one greets viewers, one flags chat toxicity, one
fetches facts, one translates for international viewers, one tracks
highlights — then after the stream, one delivers a summary and a plan for the
next one. All of it orchestrated, logged, and under the creator's control.
